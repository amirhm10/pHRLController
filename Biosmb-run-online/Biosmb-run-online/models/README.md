# Custom TD3 policy bundle

The BioSMB runtime expects these generated files in this directory:

```text
td3_actor_manifest.json
td3_actor_weights.pt
```

They are generated by the main repository after a default
`run_offline_ph_td3_training.py` run. Checkpoint saving is enabled by default;
`--no-save-checkpoint` is the explicit opt-out for disposable runs.

The deployment service loads only the actor weights. It does not load a critic,
optimizer, replay buffer, exploration process, or training checkpoint.

The current SAC ZIP and replay-buffer pickle are historical reference
artifacts. They are not loaded by the custom TD3 runtime.

Do not rename the example manifest to the live manifest name. The example has
a placeholder hash and no golden vectors, so the loader will reject it.

New training exports are intentionally marked `simulation_only: true` and all
validation/approval fields are false. Do not flip those fields by hand. An
active deployment additionally requires an independently reviewed manifest
SHA-256 in `deployment_settings.json`, verified physical mappings, exclusive
pump ownership, verified readback semantics, and a one-session arming value.
