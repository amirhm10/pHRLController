# Save TD3 By Default

## Objective

Update the offline pH TD3 runner so normal training runs save the trained agent
and deployment actor bundle automatically, and change the terminal exploration
noise standard deviation from `0.01` to `0.02`.

## Files Changed

- `run_offline_ph_td3_training.py`
- `tests/test_offline_ph_rl.py`
- `reports/offline_ph_td3_method_report.md`
- `reports/biosmb_custom_td3_implementation_walkthrough.md`
- `Biosmb-run-online/Biosmb-run-online/models/README.md`
- `change-reports/20260710_172923_save_td3_by_default.md`

## Implementation Summary

- Changed the default `--std-end` value to `0.02`.
- Replaced the opt-in `store_true` checkpoint flag with
  `argparse.BooleanOptionalAction` and `default=True`.
- Normal runs now save the complete TD3 research checkpoint.
- Default `ratio_buffer_sum` runs also save the actor-only deployment bundle.
- Added `--no-save-checkpoint` as the explicit opt-out for disposable runs.
- Added regression assertions for both the default and opt-out behavior.
- Updated current-method and BioSMB deployment documentation. Historical
  result reports describing earlier runs were intentionally preserved.

## Mathematical Interpretation

The training exploration action remains

$$
a_t^{\mathrm{explore}}
= \operatorname{clip}\left(\pi_\theta(s_t)+\epsilon_t,-1,1\right),
\qquad
\epsilon_t \sim \mathcal{N}(0,\sigma_t^2 I).
$$

The configured terminal standard deviation is now

$$
\sigma_{\mathrm{end}} = 0.02.
$$

Evaluation still uses deterministic actor inference without exploration noise.
