# Test Smaller Ratio-Preserving TD3 With Gamma 0.99

## Objective

Prepare a controlled offline experiment using smaller actor and critic networks
and a longer discount horizon. Do not change the ratio-preserving action
mapping, reward, exploration endpoint, BioSMB online runner, or existing saved
checkpoint.

## Files changed

- `run_offline_ph_td3_training.py`
- `tests/test_offline_ph_rl.py`
- `reports/offline_ph_td3_ratio_preserving_flow_algorithm.md`
- `change-reports/20260713_200416_test_smaller_td3_gamma099.md`

## Implementation summary

- Changed the offline actor default from `[128, 128]` to `[64, 64]`.
- Changed the offline critic default from `[128, 128]` to `[64, 64]`.
- Changed the offline discount factor from `0.97` to `0.99`.
- Kept total steps at 500,000, batch size at 64, final exploration noise at
  0.02, and action mode at `ratio_preserving_flow`.
- Updated the offline default test and the ratio-preserving algorithm report.
- Recorded the `[128, 128]`, `gamma = 0.97` run as the comparison baseline.
- Left all files under `Biosmb-run-online` unchanged.

This architecture and discount combination was previously tried with the older
sum-first action mapping. The new experiment is scientifically distinct because
the current mapping preserves the chosen acetate/acid ratio for every optional
flow command.
