# Configure the next offline TD3 run

## Objective

Verify the settings used by the existing offline TD3 checkpoint and configure
the next offline run to use `gamma = 0.99`, `[64, 64]` actor and critic layers,
and batch size `64`.

## Implementation summary

- Confirmed that the existing checkpoint stores `hparams["gamma"] = 0.97`.
- Confirmed that its saved `td3_training_config.json` also records `0.97`.
- Changed only the offline runner default from `0.97` to `0.99`.
- Changed the default actor and critic hidden layers from `[128, 128]` to
  `[64, 64]`.
- Confirmed that the offline batch-size default was already `64`, so it did not
  require a code change.
- Kept the existing checkpoint, saved offline configuration, and current online
  continuation configuration at `0.97`, because they describe the existing
  model and must not be silently relabeled.
- Documented that the next offline run will use `0.99` by default and that all
  matching exported model files should be replaced together after retraining.
- Made new offline checkpoints self-describing with state/action dimensions,
  actor/critic layer sizes, architecture settings, and a checkpoint schema.
- Enabled optimizer-state saving for the offline checkpoint used to start
  online adaptation.
- Added the training checkpoint and exact offline configuration to the generated
  `deployment_bundle` beside the actor manifest and weights.
- Updated the online loader to reconstruct architecture and `gamma` from a
  new-format trusted checkpoint, while retaining compatibility with the current
  legacy checkpoint and its JSON settings.
- Restored offline optimizer state when it is available, while intentionally
  starting online learning with an empty replay buffer.

- `git diff --check` passed for the changed files.

## Known limitations and next steps

- The existing checkpoint remains a `gamma = 0.97` model.
- The existing checkpoint retains its `[128, 128]` actor and critic architecture.
- The existing checkpoint remains on the legacy format and has no optimizer
  state; the new format takes effect only after the next offline run.
- Retrain offline before replacing the deployment model artifacts.
- Compare the new run against the old run; a larger discount factor gives more
  weight to longer-term return but does not guarantee better control.
- After selecting the new checkpoint, copy the checkpoint, actor weights, actor
  manifest, and saved training configuration from its `deployment_bundle` as
  one consistent set. The online loader will take `gamma` and architecture from
  the checkpoint automatically.
