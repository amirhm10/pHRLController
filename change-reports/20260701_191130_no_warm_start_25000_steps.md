# Set Offline pH TD3 To No Warm Start And 25000 Steps

## Objective

Update the offline pH TD3 runner so warm start is not part of the default offline-training protocol and the default rollout length is 25,000 steps.

## Files Changed

- `run_offline_ph_td3_training.py`
- `helpers/offline_ph_td3_results.py`
- `analysis/generate_offline_ph_td3_report.py`
- `tests/test_offline_ph_rl.py`
- `reports/offline_ph_rl_environment_report.md`
- `change-reports/20260701_191130_no_warm_start_25000_steps.md`

## Method Or Implementation Summary

- Added `resolve_set_points_len()` so the runner can define rollout length by total steps.
- Changed runner defaults to:
  - `--total-steps 25000`
  - `--n-tests 10`
  - `--set-points-len None`, resolved to `2500` by default
  - `--warm-start-cycles 0`
- Kept `--warm-start-cycles` as an explicit legacy option, but it is not used by default.
- Changed the no-warm-start initial condition to use the default flow state instead of the target-matched HH nominal flow.
- Added resolved rollout metadata to `config_snapshot.json`.
- Updated result summary logic so empty warm-start rows are not written when no warm-start segment exists.
- Updated the report generator and environment report text so they recommend the no-warm-start offline protocol.

No BioSMB, OPC emulator, hardware, MPC, valve, pump-runner, or raw lab CSV files were modified.
