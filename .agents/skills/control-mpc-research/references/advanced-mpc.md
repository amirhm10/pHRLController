# Advanced MPC Variants

## Robust MPC

Declare:

- uncertainty set
- tube or feedback policy
- constraint tightening
- terminal set
- disturbance assumptions
- recursive-feasibility argument

## Stochastic MPC

Declare:

- disturbance distribution
- scenario generation
- chance constraints
- risk measure
- probability-estimation error
- out-of-sample validation

## Nonlinear MPC

Declare:

- nonlinear model
- integration
- discretization
- initialization
- local minima
- derivative method
- real-time feasibility

## Economic MPC

Separate economic stage cost from tracking. State whether the steady state is fixed or optimized and whether dissipativity or stability assumptions are used.

## Learning-based MPC

Identify exactly what is learned:

- model
- residual
- terminal cost
- constraint
- horizon
- weight
- disturbance
- safety set
- optimizer warm start

Then audit data coverage, uncertainty, and fallback.
