# Distillation Dynamics and Control

## Variables

Common controlled variables include:

- product composition
- tray temperature
- pressure
- reflux drum level
- base level

Common manipulated variables include:

- reflux
- distillate
- bottoms
- boilup or reboiler duty
- condenser duty
- pressure valve

## Audit

- pairing and interaction
- direct or reverse action
- inventory-loop hierarchy
- analyzer delay
- inferential calibration
- actuator saturation
- pressure dependence
- feedforward
- target feasibility
- model mismatch
- hydraulic constraints

## RL or MPC distinction

Determine whether learning changes:

- direct input
- residual input
- horizon
- weight
- model or Markov parameters
- target
- estimator
- fallback decision

Then trace how that change affects vapor-liquid traffic and product quality.
