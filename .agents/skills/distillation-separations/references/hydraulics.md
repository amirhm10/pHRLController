# Column Hydraulics

## Tray checks

- vapor velocity
- active area
- froth height
- pressure drop
- weir loading
- downcomer area
- downcomer backup
- entrainment
- weeping
- dumping
- flooding fraction
- turndown

## Packing checks

- superficial gas and liquid rates
- pressure drop
- flooding
- liquid distribution
- wetting
- holdup
- packing factor
- height equivalent to a theoretical plate or rate-based transfer

## Dynamic implications

- holdup changes composition time constants
- pressure drop couples stages
- flooding can invalidate nominal models
- weeping changes effective stage efficiency
- reboiler and condenser limits constrain vapor and liquid traffic
- actuator commands should be mapped to actual hydraulic variables

## Reporting

Show operating trajectory relative to hydraulic limits, not only steady-state design points.
