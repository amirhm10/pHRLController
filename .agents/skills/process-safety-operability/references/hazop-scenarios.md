# Scenario Generation

Apply deviations to:

- feed flow and composition
- coolant or heating
- agitation
- pressure control
- level control
- product removal
- reflux and boilup
- acid and base dosing
- initiator or catalyst
- sensors
- actuators
- communication
- power and utilities
- software and solver
- startup and shutdown sequence

For each scenario record:

- initiating event
- assumptions
- expected physical sequence
- detection
- safeguards
- consequence
- simulation inputs
- acceptance criterion
- missing model physics
