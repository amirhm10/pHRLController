# Electrolyte Activity Models

## Selection questions

- ionic strength
- ion valence
- temperature
- concentration range
- mixed solvents
- available parameters
- required accuracy
- simulator compatibility

## Audit

- activity convention
- standard state
- parameter source
- charge balance
- species set
- neutral complexes
- temperature dependence
- precipitation
- gas exchange

## Sensitivity

Compare pH and species predictions under plausible activity-model choices when the application is sensitive.
