# Aqueous Equilibria

## Workflow

1. List species.
2. Define equilibrium reactions and constants.
3. Define analytical or elemental totals.
4. Write charge balance.
5. Select activity model.
6. solve for species and pH.
7. check residuals and limiting cases.

## Polyprotic systems

Track all dissociation steps and total analytical concentration. Do not apply a single Henderson-Hasselbalch expression across the full range without checking dominant species.

## Alkalinity

Define the alkalinity convention for the system. Different species and reference forms may contribute.

## Precipitation

If solids can form:

- include solubility equilibria
- check saturation indices
- update dissolved totals
- consider kinetics when equilibrium is too fast or too slow for the application
