# Search Protocol

## Query families

Construct several query families:

1. **Definition and theory**
   - exact method name
   - mathematical formulation
   - assumptions and guarantees

2. **Application**
   - method + plant, domain, or dataset
   - method + chemical process, distillation, polymer, pH, CSTR, or MPC

3. **Evaluation**
   - benchmark
   - ablation
   - reproducibility
   - comparison
   - failure mode

4. **Contradiction**
   - limitations
   - failure
   - negative results
   - instability
   - sensitivity
   - distribution shift

5. **Implementation**
   - official documentation
   - reference implementation
   - version or release notes
   - issue tracker when appropriate

## Search log

For systematic or high-stakes work, record:

| Query | Source or database | Date | Filters | Relevant results |
|---|---|---|---|---|

## Inclusion criteria

Define criteria before screening when the review is systematic:

- date range
- language
- source type
- application
- method class
- evidence type
- minimum reporting quality

## Exclusion reasons

Use explicit reasons:

- not the target method
- no relevant outcome
- duplicate
- inaccessible primary source
- superseded version
- application mismatch
- insufficient methodological detail
