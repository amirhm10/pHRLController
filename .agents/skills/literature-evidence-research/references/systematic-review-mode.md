# Systematic Review Mode

Use only when the user requests a systematic, scoping, or review-style investigation.

## Minimum protocol

1. State the review question.
2. Define databases or source systems.
3. Record search strings and date.
4. Define inclusion and exclusion criteria.
5. Remove duplicates.
6. Screen title and abstract.
7. Screen full text.
8. Extract structured evidence.
9. Assess study quality.
10. Report included and excluded counts.
11. Synthesize findings and heterogeneity.
12. Preserve the search log and evidence table.

## Evidence extraction fields

- citation
- year
- system or dataset
- method
- comparator
- sample size or seeds
- metrics
- main result
- uncertainty
- safety result
- limitations
- code or data availability
- applicability notes

Do not claim formal systematic-review compliance unless the required protocol was actually followed.
