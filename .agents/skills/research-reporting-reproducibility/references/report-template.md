# Report Template

```markdown
# [Title]

## Executive summary

State the decision question, strongest evidence, decision, and main uncertainty.

## Objective

Define the system, baseline, candidate, and hypothesis.

## Method

Describe the active implementation and equations. State physical versus scaled variables.

## Experimental setup and provenance

List runs, seeds, scenarios, data paths, software or simulator version, and metric windows.

## Results

Report numerical metrics with uncertainty. Include negative and failed results.

## Evidence

Reference verified figures, tables, derivations, tests, or solver diagnostics.

## Interpretation

Separate observations from mechanisms. Discuss alternatives.

## Limitations

State missing data, limited replication, model assumptions, and transfer limits.

## Decision and next experiment

Give a concrete decision or falsifiable next test.

## Reproducibility

List code, configuration, data, environment, and generation steps.
```
