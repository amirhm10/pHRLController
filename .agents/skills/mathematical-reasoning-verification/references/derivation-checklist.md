# Derivation Checklist

- [ ] Variables, domains, dimensions, and units defined
- [ ] Coordinate system defined
- [ ] Assumptions listed
- [ ] Initial and boundary conditions listed
- [ ] Sign conventions stated
- [ ] Continuous or discrete time stated
- [ ] Every transformation justified
- [ ] Matrix dimensions checked
- [ ] Constraints and domains preserved
- [ ] Special cases tested
- [ ] Limiting cases tested
- [ ] Potential singularities identified
- [ ] Approximation order or neglected terms stated
- [ ] Result classified as local, regional, or global
- [ ] Numerical verification performed when possible
- [ ] Conclusion does not exceed assumptions
